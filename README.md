# MeshConnect

MeshConnect — клиент для MeshCore. Подключается к совместимому радио по Bluetooth или TCP. В приложении есть каналы, личные сообщения, список узлов, карта и трассировка маршрутов.

## Установка на iPhone

IPA предназначена для физического iPhone и публикуется без подписи. Скачайте её на компьютер целиком, сохранив расширение `.ipa`. Для установки понадобятся кабель USB с передачей данных, аккаунт Apple и Sideloadly. Для личной тестовой установки подходит бесплатный аккаунт Apple. [Скачать Sideloadly](https://sideloadly.io/)

### С Mac

1. Скачайте Sideloadly для macOS и переместите приложение в папку «Программы».
2. Подключите разблокированный iPhone по USB. Откройте Finder и выберите iPhone в боковом меню. Если появится запрос, подтвердите доверие на Mac и на iPhone.
3. Откройте Sideloadly, выберите iPhone и перетащите скачанный файл IPA в окно программы. Укажите свой аккаунт Apple и нажмите **Start**. Если Sideloadly запросит пароль и код подтверждения Apple, введите их в окне программы.
4. Дождитесь окончания установки и выполните шаги из раздела [«Первый запуск на iPhone»](#первый-запуск-на-iphone).

[Как подтвердить доверие к компьютеру](https://support.apple.com/ru-ru/109054)

### С Windows

1. На сайте Sideloadly откройте загрузку для Windows и установите iTunes и iCloud по ссылкам из окна загрузки. Для этого способа Sideloadly требует версии с сайта Apple. Если установлены версии из Microsoft Store, удалите их перед установкой веб-версий. Затем установите Sideloadly.
2. Подключите разблокированный iPhone по USB. Откройте iTunes, убедитесь, что телефон появился в программе, и подтвердите доверие на iPhone.
3. Откройте Sideloadly, выберите iPhone и перетащите скачанный файл IPA в окно программы. Укажите свой аккаунт Apple и нажмите **Start**. Если появится запрос Apple, подтвердите вход.
4. Дождитесь окончания установки и выполните шаги из раздела [«Первый запуск на iPhone»](#первый-запуск-на-iphone).

[Загрузки и требования Sideloadly для Windows](https://sideloadly.io/)

### Первый запуск на iPhone

1. Откройте **Настройки → Конфиденциальность и безопасность → Режим разработчика** и включите его. Подтвердите перезагрузку, затем включение режима после перезагрузки. Если пункта ещё нет, сначала подключите iPhone к компьютеру и начните установку через Sideloadly, затем проверьте настройки снова.
2. Если при запуске MeshConnect появится сообщение о недоверенном разработчике, откройте **Настройки → Основные → VPN и управление устройством**, выберите профиль аккаунта, которым подписали приложение, и подтвердите доверие.
3. Откройте MeshConnect. Для подключения по Bluetooth разрешите приложению доступ к Bluetooth. Для подключения к MeshCore по TCP в домашней сети разрешите доступ к локальной сети, когда iPhone его запросит.

[Режим разработчика в документации Apple](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device/) · [Справка Sideloadly](https://sideloadly.io/faq.html)

### Продление подписи и обновление

С бесплатным аккаунтом профиль действует **7 дней**. Чтобы продлить его, снова подпишите и установите тот же IPA поверх приложения. При желании включите автоматическое продление в Sideloadly. Для него компьютер с работающим Sideloadly Daemon должен видеть iPhone по USB или по Wi‑Fi после настройки синхронизации.

Для обновления скачайте новый IPA и установите его поверх предыдущей версии с тем же аккаунтом Apple и тем же идентификатором приложения (Bundle ID). Если вы вручную задавали Bundle ID при первой установке, укажите его снова. Это позволяет сохранить локальные данные MeshConnect при обновлении.

[Срок профиля бесплатного аккаунта Apple](https://developer.apple.com/help/account/basics/about-your-developer-account) · [Продление и обновление в Sideloadly](https://sideloadly.io/faq.html)

### Если установка не получается

| Что происходит | Что проверить |
| --- | --- |
| Sideloadly не видит iPhone | Разблокируйте его, подтвердите доверие и проверьте подключение в Finder или iTunes. Попробуйте другой кабель с передачей данных или USB-порт. На Windows проверьте, что стоят веб-версии iTunes и iCloud. |
| iPhone сообщает, что нужен режим разработчика | Включите его в настройках, перезагрузите телефон и подтвердите включение после перезагрузки. |
| iPhone сообщает о недоверенном разработчике | Подтвердите доверие к профилю своего аккаунта в разделе «VPN и управление устройством». |
| Приложение перестало открываться через неделю | Повторно подпишите и установите IPA поверх приложения с тем же аккаунтом и Bundle ID. |
| Sideloadly сообщает о лимите приложений или идентификаторов | Для бесплатной подписи Apple действует лимит. Если заняты все места для приложений, освободите одно из них. Если исчерпан лимит идентификаторов, дождитесь освобождения лимита и повторите попытку. |

[Устранение проблем с подключением iPhone](https://support.apple.com/ru-ru/108643) · [Коды ошибок Sideloadly](https://sideloadly.io/faq.html)

## Установка на Android

Скачайте APK для архитектуры телефона, откройте его и подтвердите установку. Если Android попросит разрешение на установку приложений из этого источника, выдайте его приложению, из которого открываете APK. Публичные сборки 28, 33, 51, 52 и 54 подписаны одним тестовым ключом. Для обновления откройте APK поверх предыдущей публичной сборки.

## Проверка файла

Для сборки 54 SHA-256 всех файлов есть в [SHA256SUMS.txt](https://github.com/serggend/MeshConnect/releases/download/v0.1.0-build54/SHA256SUMS.txt). Для IPA 51 опубликована [отдельная контрольная сумма](https://github.com/serggend/MeshConnect/releases/download/v0.1.0-build51/meshconnect-iphone-0.1.0-build51-unsigned.ipa.sha256).

Выполните команду в папке со скачанным файлом и сравните полученное значение с опубликованным.

**macOS, Терминал**

```sh
shasum -a 256 meshconnect-iphone-0.1.0-build54-unsigned.ipa
```

**Windows, PowerShell**

```powershell
Get-FileHash .\meshconnect-iphone-0.1.0-build54-unsigned.ipa -Algorithm SHA256
```
